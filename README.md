# Оптический денситометр на Arduino Nano

Проект для измерения оптической плотности растворов с использованием лазера и фоторезистора.

## Особенности
- Измерение базовой линии и оптической плотности
- Расчет концентрации по калибровочным коэффициентам
- Интерактивное меню через UART

## Схема подключения
- Лазер: D2
- Фоторезистор: A0
- UART: RX/TX (D0/D1)

## Сборка
```bash
make all
make upload
```
